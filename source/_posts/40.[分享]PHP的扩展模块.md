## PHP 扩展模块完全指南

PHP 扩展模块是 PHP 语言功能的延伸和增强。它们如同一个个功能组件，让 PHP 能够连接数据库、处理图像、进行加密、发送网络请求等。本指南将系统介绍 PHP 扩展的概念，并以分类形式全面梳理各类常见扩展的用途和基本用法。

## PHP 扩展的概念与形式

### 什么是 PHP 扩展

PHP 扩展是用 C 语言编写的动态链接库，用于为 PHP 提供额外的功能。PHP 语言本身提供语法、分支、循环、函数、类等基础能力，而扩展则在 PHP 的基础上补充或扩展功能，使 PHP 变得更加强大。

扩展以"插件式"的方式管理和维护 PHP 的功能。如果将全部功能整合到 PHP 语言中，会导致 PHP 过于臃肿且不够灵活。而有了扩展机制，开发者可以根据实际需求灵活启用或禁用功能。

### PHP 扩展的存在形式

在 Linux 系统下，PHP 扩展以 `.so` 文件存在（如 `redis.so`），在 Windows 系统下则以 `.dll` 文件存在。

### 查看已安装的扩展

```php
<?php
// PHP 代码中查看所有已加载扩展
print_r(get_loaded_extensions());
?>
```

```bash
# 命令行查看
php -m
```

`get_loaded_extensions()` 函数返回一个数组，包含所有已编译并加载的扩展模块名称。

### 一、数据库驱动扩展用法

#### 1. MySQLi 扩展

MySQLi（MySQL Improved）是 PHP 操作 MySQL 数据库的原生扩展，支持面向对象和面向过程两种风格。

**面向对象方式**：
```php
<?php
$mysqli = new mysqli('localhost', 'username', 'password', 'database');

if ($mysqli->connect_errno) {
    die("连接失败: " . $mysqli->connect_error);
}

// 执行查询
$result = $mysqli->query("SELECT name, email FROM users LIMIT 5");

// 处理结果
while ($row = $result->fetch_assoc()) {
    echo $row['name'] . " - " . $row['email'] . "\n";
}

// 使用预处理语句（防 SQL 注入）
$stmt = $mysqli->prepare("SELECT name FROM users WHERE id = ?");
$stmt->bind_param("i", $id);
$id = 1;
$stmt->execute();
$stmt->bind_result($name);
while ($stmt->fetch()) {
    echo $name;
}

$mysqli->close();
?>
```

**面向过程方式**：
```php
<?php
$conn = mysqli_connect('localhost', 'username', 'password', 'database');
if (!$conn) {
    die("连接失败: " . mysqli_connect_error());
}

$result = mysqli_query($conn, "SELECT * FROM users");
while ($row = mysqli_fetch_assoc($result)) {
    print_r($row);
}
mysqli_close($conn);
?>
```

#### 2. PDO 及数据库驱动

PDO 提供统一的数据库访问接口，支持多种数据库驱动。

```php
<?php
// MySQL 连接
$pdo = new PDO('mysql:host=localhost;dbname=test;charset=utf8mb4', 'user', 'pass');
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

// 预处理查询
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = ?");
$stmt->execute([1]);
$user = $stmt->fetch(PDO::FETCH_ASSOC);

// 命名参数
$stmt = $pdo->prepare("INSERT INTO users (name, email) VALUES (:name, :email)");
$stmt->execute([':name' => '张三', ':email' => 'zhang@example.com']);

// 获取最后插入 ID
$lastId = $pdo->lastInsertId();

// PostgreSQL 连接
$pdoPg = new PDO('pgsql:host=localhost;dbname=test', 'user', 'pass');

// SQLite 连接
$pdoSqlite = new PDO('sqlite:/path/to/database.db');
?>
```

#### 3. PgSQL 扩展

PostgreSQL 数据库的原生扩展。

```php
<?php
$conn = pg_connect("host=localhost port=5432 dbname=mydb user=postgres password=secret");
if (!$conn) {
    die("连接失败: " . pg_last_error());
}

// 执行查询
$result = pg_query($conn, "SELECT id, name FROM users");
while ($row = pg_fetch_assoc($result)) {
    echo $row['name'] . "\n";
}

// 预处理语句
$result = pg_prepare($conn, "my_query", "SELECT * FROM users WHERE id = $1");
$result = pg_execute($conn, "my_query", array(1));

pg_free_result($result);
pg_close($conn);
?>
```

#### 4. SQLite3 扩展

轻量级嵌入式数据库扩展。

```php
<?php
$db = new SQLite3('database.db');

// 创建表和插入数据
$db->exec("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT)");
$db->exec("INSERT INTO users (name) VALUES ('张三')");

// 查询
$result = $db->query("SELECT * FROM users");
while ($row = $result->fetchArray(SQLITE3_ASSOC)) {
    echo $row['name'] . "\n";
}
```

#### PIE：下一代扩展管理工具

PIE（PHP Installer for Extensions）是新一代 PHP 扩展安装工具，旨在取代 PECL，解决 PECL 维护困难、依赖管理不足等问题。

```bash
# 使用 PIE 安装扩展
pie install asgrim/example_pie_extension
```

PIE 支持通过 Composer 管理扩展依赖，可以将扩展像普通 PHP 包一样声明在 `composer.json` 中。

## 总结

本文系统梳理了 PHP 各类扩展的完整列表和详细代码用法，涵盖了数据库驱动、网络通信、图像处理、数据格式、加密安全、数学计算、国际化、性能优化、队列缓存、NoSQL 等主要扩展类别。

PHP 扩展的使用核心要点可归纳为：

1. **选择合适的扩展**：根据项目需求选择扩展，MySQLi 适合 MySQL 专属项目，PDO 适合跨数据库项目
2. **安全使用**：数据库操作使用预处理语句防止 SQL 注入，加密使用 OpenSSL 或 Sodium
3. **性能优化**：使用 OPcache 缓存字节码，使用 Redis/Memcached 缓存数据
4. **安装与管理**：优先使用系统包管理器，其次选择 PECL，新项目可评估 PIE 工具

掌握这些扩展的使用方法，能够帮助开发者构建功能丰富、性能优良、安全可靠的 PHP 应用。
